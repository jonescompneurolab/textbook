1.2 Installation

If you want to run HNN for free in the browser, click on the below box and follow the directions:

Running HNN in the cloud (no installation)

Google CoLab

We provide Google CoLab notebooks that allow you to run HNN out of your browser, with access to your local filesystem.

  • GUI Colab Notebook (Graphical User Interface)
  • API Colab Notebook (Code-only, no GUI)

This is the quickest way to get up and running with HNN, though it does require a Google account. If you do not have a Google account, you can create one for free to run the notebooks. There is no charge associated with using Google CoLab.

Neuroscience Gateway Portal

If you want, instead of using Google Colab, you can run HNN for free, public use on the Neuroscience Gateway Portal (NSG). You can find instructions for using HNN on NSG at this page here.

Local Installation - Simple

If you want to install HNN-Core on your local computer with all features, including API (code), GUI (Graphical User Interface), MPI (parallel computing), and others, follow Part 1 then Part 2 below. Alternatively, if your circumstances are more complex (e.g. if you are using Anaconda/conda, you are using Brown University’s OSCAR system, you want to install for development, etc.) then please see the Local Installation - Detailed section. You can always reach out to us at our Github Discussions page for installation help!

Local Installation Part 1: Platform-specific requirements

For Part 1, click on the section for your operating system and follow the directions inside the box.

MacOS

  1. Before you install HNN-Core, you must install “Xcode Command-Line Tools”. This can be done by opening the Terminal app, then copying, pasting, and running the following command, and then clicking through the prompts in the window that will pop up.

    xcode-select --install

    If you see output that says xcode-select: note: Command line tools are already installed. then that’s okay, continue.

  2. Restart your computer.

  3. Make sure your computer has the latest updates by opening the Settings app and going to “Software Update”. Download and install all updates, then restart your computer again, then check “Software Update” again for more updates. Note that you may have to do this multiple times.

  4. Once there are no more updates to your system available, check that you are not on the Low Battery setting by clicking on your battery in the top bar. If you are set to Low Battery mode, switch it to a different battery mode.

  5. Proceed to Part 2.

Windows (WSL)

  1. Install “Windows Subsystem for Linux” (WSL). You can do this via following the steps at https://learn.microsoft.com/en-us/windows/wsl/install or the steps here:

    1.1. Open the Start Menu and type powershell, but do not hit enter or left-click the icon yet.

    1.2. Right-click on the icon for Powershell and select Run as administrator. A new window should open.

    1.3. Inside the Powershell window, run the following command, which will take several minutes:

    wsl --install

    1.4. It should eventually prompt you to Create a default Unix user account and ask for a password. Provide a username and password, which can be anything, and write the password down!

    1.5. Once it has finished, close the PowerShell window.

  2. You will now have a new App available from the Start Menu called Ubuntu. Run that app.

  3. You should now see a prompt and a blinking cursor. Copy, paste, and run the following commands. When it asks for your password, provide the password you created in the prior step 1.4.

    sudo apt-get update
sudo apt-get -y install build-essential

  4. Proceed to Part 2.

Linux (Debian/Ubuntu)

  1. Install the fundamental software building packages for your distribution. For Debian/Ubuntu-based distributions (e.g. Debian, Ubuntu, Linux Mint, etc.), you can do this with the following command in your Terminal:

    sudo apt-get update
sudo apt-get -y install build-essential

  2. Proceed to Part 2.

Local Installation Part 2: uv and HNN-Core installation

Note: This section assumes that you are not already using a Python virtual environment manager, such as poetry, pyenv, or Anaconda, among many others. If you don’t know what this means or are unsure, then move on to step 1 below. If you are, then you should create a new environment using your environment manager and run the following command from inside the environment:

pip install -U "hnn-core[all]"
python -c "
from hnn_core import neymotin_2020_model, MPIBackend, simulate_dipole
with MPIBackend(n_procs=2):
    simulate_dipole(neymotin_2020_model(), tstop=20)
print('--> SUCCESS: The test worked')"

Otherwise, continue on to Step 1.

  1. Open a new Terminal (MacOS / Linux) or Ubuntu (Windows Subsystem for Linux) window.

  2. Download and install the uv Python package and project manager by copying, pasting, and running the following command:

    curl -LsSf https://astral.sh/uv/install.sh | sh

  3. Close your Terminal / Ubuntu window, then open a new one.

  4. Copy, paste, and run the following series of commands in order to install Python, create a new “virtual environment”, install HNN-Core, and test HNN-Core. You can copy and paste all of them together at one time:

    uv python install 3.14
cd ~
uv venv -p 3.14
source .venv/bin/activate
hash -r
uv pip install -U "hnn-core[all]"
python -c "
from hnn_core import neymotin_2020_model, MPIBackend, simulate_dipole
with MPIBackend(n_procs=2):
    simulate_dipole(neymotin_2020_model(), tstop=20)
print('--> SUCCESS: The test worked')"

    If you encounter any errors or problems with this step, please reach out to us on our Github Discussions page. If you want, you can view this page or this page for more guidance on using “virtual environments”.

  5. Close your Terminal / Ubuntu window again, then open a new one.

  6. Copy, paste, and run the following command to re-activate your “virtual environment” that contains HNN-Core. Note that you will need to do this each time you open a new Terminal/Ubuntu window, or if you restart your computer and want to use HNN-Core again:

    source ~/.venv/bin/activate

  7. Once you have activated your environment, you can run the GUI using the following command:

    hnn-gui

  8. Everything should be installed and working now! As a reminder, if you restart your computer or open new Terminal/Ubuntu windows, then you will have to “activate your virtual environment” once again to use the HNN-Core API or the GUI. You can do this using the following command:

    source ~/.venv/bin/activate

    After which you can run hnn-gui to open the GUI, run python code/files using python or ipython, or open Jupyter notebooks using jupyter notebook. Proceed to the rest of our HNN Textbook to get started!

Local Installation - Detailed

This section intended for advanced users or if you are having issues installing HNN-Core on Windows. If the above Windows (WSL) install did not work for you, then please either try the non-WSL Windows Installation section below or reach out to us on our Github Discussions page and we will happily assist you.

There are a few cases where you should not follow the above “simple” directions:

  • If you want to co-install HNN alongside MNE: In this case, we strongly recommend that you install MNE first (MNE install guides here). If you installed MNE using its pip or conda methods, then afterwards, you should install HNN using the command pip install "hnn-core[all]", but only in the same Python environment that you installed MNE into.

  • If you are using your institution’s High-Performance Computing (HPC) environment (also called a “computing cluster” or supercomputer): Refer to your HPC’s documentation (or ask an HPC colleague) whether your HPC supports conda or uv. If they only support conda, then follow these directions below, except that you should not install Anaconda, and there will likely be additional steps that you need to adapt to your HPC’s configuration. Additionally, if you are using an HPC, then after you have installed HNN-Core, you should run uv pip uninstall openmpi. This will allow you to use your HPC’s custom MPI libraries, but this will require additional configuration unique to your HPC. You can always ask us for help at our Github Discussions page.

  • If you are at Brown University and want to use HNN on the OSCAR system: We have made custom instructions for you, which can be found here at this other page.

  • If you previously installed our custom conda package via conda install hnn-core-all -c jonescompneurolab -c conda-forge (note: this is different from our pip package at pip install "hnn-core[all]"), then we recommend you stop using that conda environment and instead reinstall HNN-Core using our above “simple” directions. We have discontinued our custom conda package, and are no longer updating it.

  • If you want to use a “custom” version of HNN’s source code: This includes if you need to use your own “Github fork”, someone else’s fork, or if you want to contribute to HNN’s development. In this case, you should follow the Install from Source Code section below.

Anaconda / conda

We recommend using uv to install Python and manage your enviroments, but if you prefer or must use the Anaconda Python Distribution (aka conda), then HNN-Core works there too. You can install HNN-Core in a conda environment using the following:

  1. Install Anaconda Python Distribution if you have not already done so. If you are unfamiliar with using Anaconda/Conda virtual environments, you can find guidance about them here.

  2. Open either your Terminal app (MacOS / Linux) or the Anaconda Prompt app if you installed Anaconda on Windows.

  3. Accept the terms of service by copying, pasting, and running the following commands:

    conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r

  4. Create a conda environment if you have not already done so by copying, pasting, and running the following command:

    conda create -y -q -n hnn-core-env python=3.14

  5. Activate the conda environment using the following command. Note that you must do this every time you open a new Terminal/Anaconda Prompt window or after you restart your computer.

    conda activate hnn-core-env

  6. Finally, install and test HNN-Core using the following commands:

    pip install "hnn-core[all]"
python -c "
from hnn_core import neymotin_2020_model, simulate_dipole
simulate_dipole(neymotin_2020_model(), tstop=20)
print('--> SUCCESS: The test worked')"

  7. You can start the GUI by running the following command:

    hnn-gui

  8. Everything should be installed and working now! As a reminder, if you restart your computer or open new Terminal/Anaconda Prompt windows, then you will have to “activate your virtual environment” once again to use the HNN-Core API or the GUI. You can do this using the following command:

    conda activate hnn-core-env

    After which you can run hnn-gui to open the GUI, run python code/files using python or ipython, or open Jupyter notebooks using jupyter notebook. Proceed to the rest of our HNN Textbook to get started!

non-WSL Windows Installation

On Windows, we strongly recommend you first try the “Windows (WSL)” (Windows Subsystem for Linux) install above. The following instructions are only for those who strictly cannot use WSL, such as due to hospital IT policy. Using “plain” Windows is discouraged since we do not support MPI usage on the platform (only on Windows-WSL), the installation is complex, and it is more difficult to develop for HNN-Core on. If you run into any issues installing on Windows, please feel free to reach out to us on our Github Discussions page.

  1. Before you install HNN, it is important that you download and then install the NEURON software system-wide using its Windows-specific binaries, such as this one; you can see more information at this link.

  1. Open the Start Menu and type powershell, but do not hit enter or left-click the icon yet.

  2. Right-click on the icon for Powershell and select “Run as administrator”. A new window should open.

  3. Inside the Powershell window, copy, paste, and run the following command, then press Y for Yes. If you are unable to do this step, then reach out to us at our Github Discussions page.

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned

  4. Copy, paste, and run the following commands (you can paste them all together), which will take several minutes:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
# Install Python:
uv python install 3.14
# Move to your "home" directory (where the environment will live, feel free to change):
cd ~
# Create a virtual environment at `.venv/` that uses the above Python version:
uv venv -p 3.14
# Activate / enter the environment:
.venv\Scripts\activate
# Now that you're inside the environment, install HNN-Core:
uv pip install -U "hnn-core[all]"
# Test that HNN-Core runs correctly
python -c "
from hnn_core import neymotin_2020_model, simulate_dipole
simulate_dipole(neymotin_2020_model(), tstop=20)
print('--> SUCCESS: The test worked')
" # make sure to include this ending quote

  5. Close the Powershell window, then open a new one.

  6. Copy, paste, and run the following command to re-activate your “virtual environment” that contains HNN-Core. Note that you will need to do this each time you open a new Powershell window, or if you restart your computer and want to use HNN-Core:

    cd ~
.venv\Scripts\activate

  7. Once you have activated your environment, you can run the GUI using the following command. Do this now:

    hnn-gui

  8. Everything should be installed and working now! As a reminder, if you restart your computer or open new Powershell windows, then you will have to “activate your virtual environment” once again to use the HNN-Core API or the GUI. You can do this using the following command:

    cd ~
.venv\Scripts\activate

    After which you can run hnn-gui to open the GUI, run python code/files using python, or open Jupyter notebooks using jupyter notebook. Proceed to the rest of our HNN Textbook to get started.

Install from Source code

This method should only be used if you need to install a custom version of HNN from Github, need to edit the code yourself, or want to contribute to HNN development.

  1. First, follow all the instructions of Part 1 of the simple installation.

  2. Setup git using the instructions here. Note that you need to do two steps:

    2.1. Make sure that git is installed using these steps. Note that if you are on Windows Subsystem for Linux, you need to install git using the Linux commands inside your Ubuntu window, not the Windows commands.

    2.2. Make sure that your git program has authenticated to Github using these steps. Create a Github account if you do not have one.

  3. Open a Terminal (MacOS / Linux) or Ubuntu window (Windows Subsystem for Linux).

  4. Download and install the uv Python package and project manager by copying, pasting, and running the following command:

    curl -LsSf https://astral.sh/uv/install.sh | sh

  5. Close the Terminal/Ubuntu window, then open a new one.

  6. Identify which Github “fork” you are interested in downloading. If you are working with a colleague then ask them which fork you should download. If not, then create your own fork of https://github.com/jonescompneurolab/hnn-core , and clone your new fork.

  7. In your Terminal/Ubuntu window, run the command

    git clone <fork URL>

    Where the URL is the website address of which fork you want to use. For example, if you wanted to download Austin Soplata’s personal fork, you would run git clone https://github.com/asoplata/hnn-core.

  8. Enter the directory that you just downloaded, using the command cd hnn-core.

  9. Enter the command pwd. This will show you the path to where your code has been stored. Write down this location, since this is where you will be modifying the code of HNN.

  10. If you are working with a colleague and they require you to switch to a different “git branch”, then ask them which branch to use and for help doing so.

  11. Copy, paste, and run the following series of commands in order to install Python, create a new “virtual environment”, install HNN-Core, and test HNN-Core. You can copy and paste all of them together at one time:

    uv python install 3.14
uv venv -p 3.14
source .venv/bin/activate
hash -r
uv pip install --editable ".[dev]"
python -c "
from hnn_core import neymotin_2020_model, MPIBackend, simulate_dipole
with MPIBackend(n_procs=2):
  simulate_dipole(neymotin_2020_model(), tstop=20)
print('--> SUCCESS: The test worked')"

  12. You’re done! If you had no errors, then HNN has been installed from source code! This is an “editable” Python install, so as you make changes to the Python code, rerunning your code should use your changes automatically (note that this does not apply to MOD files). If you encounter any errors or problems with this step, please reach out to us on our Github Discussions page. If you want, you can view this page or this page for more guidance on using “virtual environments”.

  13. As a reminder, if you restart your computer or open new Terminal/Ubuntu windows, then you will have to “activate your virtual environment” once again to use the HNN. You can do this using the following command:

    source <where the code is located>/.venv/bin/activate

    After which you can run hnn-gui to open the GUI, run python code/files using python or ipython, or open Jupyter notebooks using jupyter notebook. Proceed to the rest of our HNN Textbook to get started!
